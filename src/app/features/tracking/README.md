# Tracking (Seguimiento)

Módulo para consultar públicamente el estado de un trámite y administrar su
gestión interna.

Las páginas, servicio de gestión y modelos propios permanecen dentro de esta
feature. La consulta pública de FUT reutiliza su API pública en vez de duplicar
endpoints.

## Rutas

| Ruta | Componente | Acceso |
|------|-----------|--------|
| `/seguimiento` | `TrackingComponent` | Público |
