Roles del sistema

Los siguientes roles tienen acceso al panel administrativo.

Rol Descripción Acceso
DIRECTORA Directora de la institución educativa Panel completo de trámites, solicitantes y reportes
SECRETARIA Secretaria administrativa Panel completo de trámites, solicitantes y reportes
ADMIN Administrador del sistema Acceso total al sistema
Gestión de cuentas: La creación, modificación y desactivación de cuentas administrativas se realiza directamente en SQL Server mediante el procedimiento documentado. Los hashes de contraseñas se generan con BCrypt a través del endpoint GET /v1/api/hash?password=... (uso interno del equipo de desarrollo).
